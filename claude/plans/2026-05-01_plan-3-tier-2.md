# Plan 3 — Tier 2 modeling features (round-trip)

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:subagent-driven-development` (recommended) or
> `superpowers:executing-plans` to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Round-trip the spec's "Tier 2 — Modeling essentials" features
through `xlsx → source → xlsx` with full fidelity:

- Conditional formatting
- Cell comments / notes
- Frozen panes
- Print areas
- Excel "ListObject" tables (deliberately *not* the legacy "data
  tables" / what-if feature)

**Architecture:**
- Each feature gets one or two small dataclasses in
  `src/claudesheets/model/`. Dataclasses are frozen where they don't
  hold mutable state (consistent with `Cell`, `CellFormat`).
- `Sheet` and (where appropriate) `Workbook` gain new fields holding
  lists of these objects.
- `xlsx/reader.py` and `xlsx/writer.py` extend to translate to/from
  openpyxl's representations. We do **not** introduce new openpyxl
  abstractions; we sit on top of the ones it already exposes.
- `source/yaml_sidecar.py` extends to serialize/parse the new fields.
  The `.md` table is unchanged.
- `source/markdown.py` is unchanged — comments/CF/etc. go in the
  YAML sidecar, not the table. The Markdown table stays approachable
  for non-technical humans (per spec).
- For workbook-level state (print areas, defined names belonging to
  Excel tables) we use the existing `workbook.toml` machinery in
  `config.py` plus per-sheet YAML where natural. Print areas are a
  workbook-scoped defined name in xlsx, but they map cleanly to
  per-sheet state for users; we surface them as a `print_area`
  string on `Sheet`.

**Tech stack:** Python 3.11, openpyxl (already a runtime dep),
ruamel.yaml (already), tomli-w / tomllib (already). No new
dependencies.

## Scope notes

- **Comments:** Excel has both "legacy comments" (boxes with author /
  text) and the newer "threaded comments" (Microsoft 365 review
  threads). openpyxl reads/writes only the legacy form, so that's
  what we round-trip. Threaded comments are out of scope; an
  imported workbook with threaded comments will lose them on rebuild
  (we will print a warning during `import` in a follow-up plan, not
  here).
- **Conditional formatting:** openpyxl exposes a typed hierarchy
  (`CellIsRule`, `FormulaRule`, `ColorScaleRule`, `DataBarRule`,
  `IconSetRule`). We model each rule as a tagged dict on disk to
  preserve fidelity without inventing a parallel type system; the
  reader/writer translate between dicts and openpyxl rule objects.
  This keeps the YAML round-trippable for all five rule families
  without committing to a Python-side type for each.
- **ListObject tables:** Excel's named tables (a.k.a. "structured
  references"). Data tables (the what-if `=TABLE(...)` feature) are
  explicitly NOT supported per spec. openpyxl exposes `Table` with
  fields for `displayName`, `ref`, header/totals row counts, and
  per-column metadata. We round-trip these.
- **Frozen panes:** `Sheet.frozen_panes` already exists in the model
  as `Optional[str]` (e.g. `'B2'`) — Plan 1 reserved the field. This
  plan wires it up end-to-end.
- **Print areas:** A workbook-scoped defined name (`Sheet1!Print_Area`
  → `$A$1:$E$10`). Surface as `Sheet.print_area: Optional[str]`
  (an A1 range, sheet implied).

`src/claudesheets/model/conditional.py`:

```python
"""Conditional formatting rules.

We model each rule as a tagged dict to preserve openpyxl's full
expressiveness without committing to a parallel Python type system
for the five rule families (cell_is, formula, color_scale,
data_bar, icon_set). The `kind` field selects the family; `params`
holds family-specific values; `style` (when applicable) holds the
visual treatment as a tagged dict.

This is a deliberate trade: dicts are ugly to compose by hand but
trivial to round-trip, and the alternative — five frozen dataclasses
with overlapping but not identical fields — is more code for less
clarity.
"""

from __future__ import annotations

from dataclasses import dataclass, field
from typing import Any, Dict, List, Optional


@dataclass
class ConditionalFormat:
    ranges: List[str] = field(default_factory=list)
    kind: str = 'cell_is'
    params: Dict[str, Any] = field(default_factory=dict)
    style: Optional[Dict[str, Any]] = None
    priority: Optional[int] = None
    stop_if_true: bool = False
```

```python
    totals_function: Optional[str] = None  # 'sum', 'average', etc.

    ref: str  # e.g. 'A1:C10'
```

## Task 4: Conditional formatting round-trip

**Files:**
- Modify: `src/claudesheets/xlsx/reader.py`
- Modify: `src/claudesheets/xlsx/writer.py`
- Modify: `src/claudesheets/source/yaml_sidecar.py`
- Create: `tests/test_xlsx_conditional_roundtrip.py`

The most involved Tier 2 feature. openpyxl exposes conditional
formatting via `worksheet.conditional_formatting` (a
`ConditionalFormattingList`). Each entry has a range (or a
multi-range), a list of rules, and each rule is one of five typed
classes:

- `CellIsRule` — kind=`'cell_is'` (e.g. `>0`, `between 1 and 5`).
- `FormulaRule` — kind=`'formula'`.
- `ColorScaleRule` — kind=`'color_scale'`.
- `DataBarRule` — kind=`'data_bar'`.
- `IconSetRule` — kind=`'icon_set'`.

We translate each in/out via small helpers. The model stores tagged
dicts (`ConditionalFormat.kind` + `params` + `style`); the reader and
writer maintain that translation in one place.

- [ ] **Step 1: Write the failing tests**

`tests/test_xlsx_conditional_roundtrip.py`:

```python
from pathlib import Path

import openpyxl
from openpyxl.formatting.rule import (
    CellIsRule,
    ColorScaleRule,
    FormulaRule,
)
from openpyxl.styles import PatternFill

from claudesheets.xlsx.reader import read_xlsx
from claudesheets.xlsx.writer import write_xlsx


def _wb_with_cell_is(path: Path) -> None:
    wb = openpyxl.Workbook()
    ws = wb.active
    ws.title = 'S'
    rule = CellIsRule(
        operator='greaterThan',
        formula=['0'],
        fill=PatternFill(fill_type='solid', start_color='FF00FF00'),
    )
    ws.conditional_formatting.add('A1:A10', rule)
    wb.save(path)


def _wb_with_formula(path: Path) -> None:
```

```python
"""Translate openpyxl conditional-formatting rules <-> ConditionalFormat.

We support the five rule families openpyxl exposes:
    cell_is, formula, color_scale, data_bar, icon_set.

Round-trip is structural: the same logical rule comes back, but
visual fidelity for fills/icons depends on what openpyxl serializes.
"""

from __future__ import annotations

from typing import Any, Dict, List, Optional

from openpyxl.formatting.formatting import ConditionalFormatting
from openpyxl.formatting.rule import (
    CellIsRule,
    ColorScaleRule,
    DataBarRule,
    FormulaRule,
    IconSetRule,
    Rule,
)
from openpyxl.styles import PatternFill
from openpyxl.styles.differential import DifferentialStyle

from claudesheets.model.conditional import ConditionalFormat


def cf_from_openpyxl_rule(
    ranges: List[str], rule: Rule
) -> ConditionalFormat:
    kind, params, style = _classify(rule)
    return ConditionalFormat(
        ranges=list(ranges),
        kind=kind,
        params=params,
        style=style,
        priority=rule.priority,
        stop_if_true=bool(getattr(rule, 'stopIfTrue', False)),
    )


def cf_to_openpyxl_rule(cf: ConditionalFormat) -> Rule:
    if cf.kind == 'cell_is':
        return CellIsRule(
            operator=cf.params.get('operator', 'equal'),
            formula=list(cf.params.get('formula') or []),
            fill=_fill_from_style(cf.style),
            stopIfTrue=cf.stop_if_true,
        )
    if cf.kind == 'formula':
        return FormulaRule(
            formula=list(cf.params.get('formula') or []),
            fill=_fill_from_style(cf.style),
            stopIfTrue=cf.stop_if_true,
        )
    if cf.kind == 'color_scale':
        return ColorScaleRule(
            start_type=cf.params.get('start_type', 'min'),
            start_value=cf.params.get('start_value'),
            start_color=cf.params.get('start_color', 'FFFFFFFF'),
            mid_type=cf.params.get('mid_type'),
            mid_value=cf.params.get('mid_value'),
            mid_color=cf.params.get('mid_color'),
            end_type=cf.params.get('end_type', 'max'),
            end_value=cf.params.get('end_value'),
            end_color=cf.params.get('end_color', 'FF000000'),
        )
    if cf.kind == 'data_bar':
        return DataBarRule(
            start_type=cf.params.get('start_type', 'min'),
            start_value=cf.params.get('start_value'),
            end_type=cf.params.get('end_type', 'max'),
            end_value=cf.params.get('end_value'),
            color=cf.params.get('color', 'FF638EC6'),
            showValue=bool(cf.params.get('show_value', True)),
        )
    if cf.kind == 'icon_set':
        return IconSetRule(
            icon_style=cf.params.get('icon_style', '3TrafficLights1'),
            type=cf.params.get('type', 'percent'),
            values=list(cf.params.get('values') or [0, 33, 67]),
        )
    raise ValueError(f'unknown conditional format kind: {cf.kind!r}')


def _classify(rule: Rule) -> tuple[str, Dict[str, Any], Optional[Dict[str, Any]]]:
    style = _style_from_dxf(rule.dxf) if rule.dxf else None

    if rule.type == 'cellIs':
        return (
            'cell_is',
            {
                'operator': rule.operator,
                'formula': list(rule.formula or []),
            },
            style,
        )
    if rule.type == 'expression':
        return (
            'formula',
            {'formula': list(rule.formula or [])},
            style,
        )
    if rule.type == 'colorScale' and rule.colorScale is not None:
        cs = rule.colorScale
        params: Dict[str, Any] = {}
        if cs.cfvo and len(cs.cfvo) >= 1:
            params['start_type'] = cs.cfvo[0].type
            params['start_value'] = cs.cfvo[0].val
        if cs.cfvo and len(cs.cfvo) == 3:
            params['mid_type'] = cs.cfvo[1].type
            params['mid_value'] = cs.cfvo[1].val
            params['end_type'] = cs.cfvo[2].type
            params['end_value'] = cs.cfvo[2].val
        elif cs.cfvo and len(cs.cfvo) == 2:
            params['end_type'] = cs.cfvo[1].type
            params['end_value'] = cs.cfvo[1].val
        if cs.color:
            colors = [c.value or c.rgb or '' for c in cs.color]
            if len(colors) >= 1:
                params['start_color'] = colors[0]
            if len(colors) == 3:
                params['mid_color'] = colors[1]
                params['end_color'] = colors[2]
            elif len(colors) == 2:
                params['end_color'] = colors[1]
        return 'color_scale', params, style
    if rule.type == 'dataBar' and rule.dataBar is not None:
        db = rule.dataBar
        params = {}
        if db.cfvo and len(db.cfvo) >= 2:
            params['start_type'] = db.cfvo[0].type
            params['start_value'] = db.cfvo[0].val
            params['end_type'] = db.cfvo[1].type
            params['end_value'] = db.cfvo[1].val
        if db.color:
            params['color'] = db.color.value or db.color.rgb or ''
        params['show_value'] = bool(db.showValue)
        return 'data_bar', params, style
    if rule.type == 'iconSet' and rule.iconSet is not None:
        ic = rule.iconSet
        params = {
            'icon_style': ic.iconSet,
            'type': ic.cfvo[0].type if ic.cfvo else 'percent',
            'values': [c.val for c in ic.cfvo] if ic.cfvo else [],
        }
        return 'icon_set', params, style

    # Unknown rule kind — fall through to a tagged "raw" form.
    return (
        'unknown',
        {'type': rule.type},
        style,
    )


def _style_from_dxf(dxf: DifferentialStyle) -> Dict[str, Any]:
    out: Dict[str, Any] = {}
    if dxf.fill is not None:
        fg = getattr(dxf.fill, 'fgColor', None)
        if fg is not None and (fg.value or fg.rgb):
            out['fill'] = fg.value or fg.rgb
    if dxf.font is not None:
        out['font'] = {
            'bold': bool(dxf.font.b),
            'italic': bool(dxf.font.i),
            'color': (
                dxf.font.color.value or dxf.font.color.rgb
                if dxf.font.color
                else None
            ),
        }
    return out


def _fill_from_style(style: Optional[Dict[str, Any]]) -> Optional[PatternFill]:
    if not style or 'fill' not in style:
        return None
    return PatternFill(fill_type='solid', start_color=style['fill'])
```

This module is the only place that knows the rule-translation
details. The reader and writer just call the two public helpers.
