# Plan 3 — Tier 2 modeling features (round-trip)

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:subagent-driven-development` (recommended) or
> `superpowers:executing-plans` to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Round-trip the spec's "Tier 2 — Modeling essentials" features
through `xlsx → source → xlsx` with full fidelity:

- Conditional formatting
- Cell comments / notes
- Frozen panes
- Print areas
- Excel "ListObject" tables (deliberately *not* the legacy "data
  tables" / what-if feature)

**Architecture:**
- Each feature gets one or two small dataclasses in
  `src/claudesheets/model/`. Dataclasses are frozen where they don't
  hold mutable state (consistent with `Cell`, `CellFormat`).
- `Sheet` and (where appropriate) `Workbook` gain new fields holding
  lists of these objects.
- `xlsx/reader.py` and `xlsx/writer.py` extend to translate to/from
  openpyxl's representations. We do **not** introduce new openpyxl
  abstractions; we sit on top of the ones it already exposes.
- `source/yaml_sidecar.py` extends to serialize/parse the new fields.
  The `.md` table is unchanged.
- `source/markdown.py` is unchanged — comments/CF/etc. go in the
  YAML sidecar, not the table. The Markdown table stays approachable
  for non-technical humans (per spec).
- For workbook-level state (print areas, defined names belonging to
  Excel tables) we use the existing `workbook.toml` machinery in
  `config.py` plus per-sheet YAML where natural. Print areas are a
  workbook-scoped defined name in xlsx, but they map cleanly to
  per-sheet state for users; we surface them as a `print_area`
  string on `Sheet`.

**Tech stack:** Python 3.11, openpyxl (already a runtime dep),
ruamel.yaml (already), tomli-w / tomllib (already). No new
dependencies.

## Scope notes

- **Comments:** Excel has both "legacy comments" (boxes with author /
  text) and the newer "threaded comments" (Microsoft 365 review
  threads). openpyxl reads/writes only the legacy form, so that's
  what we round-trip. Threaded comments are out of scope; an
  imported workbook with threaded comments will lose them on rebuild
  (we will print a warning during `import` in a follow-up plan, not
  here).
- **Conditional formatting:** openpyxl exposes a typed hierarchy
  (`CellIsRule`, `FormulaRule`, `ColorScaleRule`, `DataBarRule`,
  `IconSetRule`). We mirror that on the Python side with five frozen
  dataclasses inheriting from a small `ConditionalFormatBase`, plus
  a `ConditionalFormat` union type alias that `Sheet.conditional_formats`
  holds. The YAML serializer adds a `kind` tag to round-trip the
  variant cleanly, but the in-memory representation is fully typed —
  user code reads `cell_is.operator` / `color_scale.start_type` with
  IDE completion and mypy support, not stringly-typed `params['operator']`
  lookups. The lossy "style" block (fill colour + a few font attrs)
  is a separate small frozen dataclass `CFStyle`; full
  `DifferentialStyle` round-trip is intentionally out of scope.
- **ListObject tables:** Excel's named tables (a.k.a. "structured
  references"). Data tables (the what-if `=TABLE(...)` feature) are
  explicitly NOT supported per spec. openpyxl exposes `Table` with
  fields for `displayName`, `ref`, header/totals row counts, and
  per-column metadata. We round-trip these.
- **Frozen panes:** `Sheet.frozen_panes` already exists in the model
  as `Optional[str]` (e.g. `'B2'`) — Plan 1 reserved the field. This
  plan wires it up end-to-end.
- **Print areas:** A workbook-scoped defined name (`Sheet1!Print_Area`
  → `$A$1:$E$10`). Surface as `Sheet.print_area: Optional[str]`
  (an A1 range, sheet implied).

`src/claudesheets/model/conditional.py`:

```python
"""Conditional formatting rules.

A typed hierarchy mirroring openpyxl's five rule families:
    CellIsRule, FormulaRule, ColorScaleRule, DataBarRule, IconSetRule.

`Sheet.conditional_formats` holds a list of `ConditionalFormat` (the
union alias). User code dispatches with `isinstance` or `match`, and
each subclass exposes typed fields (no stringly-typed param dicts).

`CFStyle` carries the small subset of visual-style attributes we
round-trip for `CellIsRule`/`FormulaRule` (fill colour + font bold/
italic/colour). Full `DifferentialStyle` fidelity is out of scope.
"""

from __future__ import annotations

from dataclasses import dataclass
from typing import Optional, Tuple, Union


@dataclass(frozen=True)
class CFStyle:
    """Lossy subset of openpyxl's DifferentialStyle.

    Sufficient for the common econometric uses (fill highlight + bold
    text). Borders, gradient fills, named numFmts, etc. are dropped on
    round-trip. See test_xlsx_conditional_lossiness.py for the
    documented boundary.
    """

    fill_color: Optional[str] = None
    font_bold: bool = False
    font_italic: bool = False
    font_color: Optional[str] = None


@dataclass(frozen=True)
class ConditionalFormatBase:
    """Common fields shared by every rule family.

    `ranges` is a tuple of A1 range strings (frozen). `priority` is
    Excel's rule-evaluation order (lower runs first). `stop_if_true`
    short-circuits subsequent rules on a match.
    """

    ranges: Tuple[str, ...] = ()
    priority: Optional[int] = None
    stop_if_true: bool = False


@dataclass(frozen=True)
class CellIsRule(ConditionalFormatBase):
    """Comparison-against-value rule, e.g. `>0`, `between 1 and 5`.

    `operator` is one of:
        equal, notEqual, greaterThan, greaterThanOrEqual,
        lessThan, lessThanOrEqual, between, notBetween.
    `formula` is a tuple of 1 (most operators) or 2 (between/
    notBetween) cell-formula strings.
    """

    operator: str = 'equal'
    formula: Tuple[str, ...] = ()
    style: Optional[CFStyle] = None


@dataclass(frozen=True)
class FormulaRule(ConditionalFormatBase):
    """Rule that fires when an arbitrary formula evaluates truthy."""

    formula: str = ''
    style: Optional[CFStyle] = None


@dataclass(frozen=True)
class ColorScaleRule(ConditionalFormatBase):
    """Two- or three-stop colour scale.

    A two-stop scale leaves `mid_*` fields as None; a three-stop scale
    sets all three.
    """

    start_type: str = 'min'
    start_value: Optional[str] = None
    start_color: str = 'FFFFFFFF'
    mid_type: Optional[str] = None
    mid_value: Optional[str] = None
    mid_color: Optional[str] = None
    end_type: str = 'max'
    end_value: Optional[str] = None
    end_color: str = 'FF000000'


@dataclass(frozen=True)
class DataBarRule(ConditionalFormatBase):
    start_type: str = 'min'
    start_value: Optional[str] = None
    end_type: str = 'max'
    end_value: Optional[str] = None
    color: str = 'FF638EC6'
    show_value: bool = True


@dataclass(frozen=True)
class IconSetRule(ConditionalFormatBase):
    icon_style: str = '3TrafficLights1'
    type: str = 'percent'
    values: Tuple[str, ...] = ('0', '33', '67')


ConditionalFormat = Union[
    CellIsRule, FormulaRule, ColorScaleRule, DataBarRule, IconSetRule
]
```

Notes for implementers:
- All subclasses are frozen and inherit from a frozen base. Default
  values mean field-ordering rules are satisfied (no non-default
  follows a default).
- `ranges`, `formula`, `values` use `Tuple[str, ...]` rather than
  `List[str]` so the dataclasses remain genuinely immutable. Tests
  and translators construct tuples explicitly.

import openpyxl
from openpyxl.comments import Comment as XComment

from claudesheets.xlsx.reader import read_xlsx
from claudesheets.xlsx.writer import write_xlsx


def _wb_with_comment(
    path: Path, addr: str, author: str, text: str
) -> None:
    wb = openpyxl.Workbook()
    ws = wb.active
    ws.title = 'S'
    ws[addr] = 1
    ws[addr].comment = XComment(text, author)
    wb.save(path)


def test_reader_picks_up_comment(tmp_path: Path):
    src = tmp_path / 'in.xlsx'
    _wb_with_comment(src, 'B2', 'Alice', 'Check this')
    wb = read_xlsx(src)
    s = wb.sheet('S')

The most involved Tier 2 feature. openpyxl exposes conditional
formatting via `worksheet.conditional_formatting` (a
`ConditionalFormattingList`). The public iteration is:

```python
for item in ws.conditional_formatting:           # ConditionalFormatting wrapper
    ranges = tuple(str(r) for r in item.sqref.ranges)
    for rule in item.rules:                       # public list of Rule objects
        ...
```

(Verified empirically on openpyxl 3.1; do **not** use the private
`_cf_rules` attribute.)

Each `rule.type` selects one of our five typed dataclasses
(`CellIsRule` / `FormulaRule` / `ColorScaleRule` / `DataBarRule` /
`IconSetRule`). `cf_translate.py` is the only place that knows the
openpyxl ↔ model translation; reader and writer call its two public
helpers.

The visual-style block (`CFStyle`) is intentionally lossy: it captures
fill colour and a small font subset because that's what openpyxl
emits via `DifferentialStyle` for these rules in practice. Borders,
gradient fills, named numFmts inside CF rules drop on round-trip.
A dedicated lossiness test documents the boundary.

```python
"""Translate openpyxl conditional-formatting rules <-> typed CF model.

Each `rule.type` (string from xlsx) maps to one of our five frozen
dataclasses; each dataclass maps back to the corresponding openpyxl
`*Rule` constructor. Unknown rule types raise — we don't silently
drop them.
"""

from __future__ import annotations

from typing import Optional, Tuple

from openpyxl.formatting.rule import (
    CellIsRule as XCellIsRule,
    ColorScaleRule as XColorScaleRule,
    DataBarRule as XDataBarRule,
    FormulaRule as XFormulaRule,
    IconSetRule as XIconSetRule,
    Rule,
)
from openpyxl.styles import PatternFill
from openpyxl.styles.differential import DifferentialStyle

from claudesheets.model.conditional import (
    CellIsRule,
    CFStyle,
    ColorScaleRule,
    ConditionalFormat,
    DataBarRule,
    FormulaRule,
    IconSetRule,
)


def cf_from_openpyxl_rule(
    ranges: Tuple[str, ...], rule: Rule
) -> ConditionalFormat:
    style = _style_from_dxf(rule.dxf) if rule.dxf else None
    common = {
        'ranges': ranges,
        'priority': rule.priority,
        'stop_if_true': bool(getattr(rule, 'stopIfTrue', False)),
    }

    if rule.type == 'cellIs':
        return CellIsRule(
            **common,
            operator=rule.operator or 'equal',
            formula=tuple(rule.formula or ()),
            style=style,
        )
    if rule.type == 'expression':
        formulas = list(rule.formula or [])
        return FormulaRule(
            **common,
            formula=formulas[0] if formulas else '',
            style=style,
        )
    if rule.type == 'colorScale' and rule.colorScale is not None:
        cs = rule.colorScale
        cfvo = list(cs.cfvo or [])
        colors = [_color_value(c) for c in (cs.color or [])]

        def _at(seq, i, default=None):
            return seq[i] if i < len(seq) else default

        if len(cfvo) == 3:
            return ColorScaleRule(
                **common,
                start_type=cfvo[0].type,
                start_value=_str_or_none(cfvo[0].val),
                start_color=_at(colors, 0, 'FFFFFFFF'),
                mid_type=cfvo[1].type,
                mid_value=_str_or_none(cfvo[1].val),
                mid_color=_at(colors, 1),
                end_type=cfvo[2].type,
                end_value=_str_or_none(cfvo[2].val),
                end_color=_at(colors, 2, 'FF000000'),
            )
        # 2-stop scale (or sparse cfvo)
        return ColorScaleRule(
            **common,
            start_type=cfvo[0].type if cfvo else 'min',
            start_value=_str_or_none(cfvo[0].val) if cfvo else None,
            start_color=_at(colors, 0, 'FFFFFFFF'),
            end_type=cfvo[1].type if len(cfvo) > 1 else 'max',
            end_value=(
                _str_or_none(cfvo[1].val) if len(cfvo) > 1 else None
            ),
            end_color=_at(colors, 1, 'FF000000'),
        )
    if rule.type == 'dataBar' and rule.dataBar is not None:
        db = rule.dataBar
        cfvo = list(db.cfvo or [])
        return DataBarRule(
            **common,
            start_type=cfvo[0].type if cfvo else 'min',
            start_value=_str_or_none(cfvo[0].val) if cfvo else None,
            end_type=cfvo[1].type if len(cfvo) > 1 else 'max',
            end_value=(
                _str_or_none(cfvo[1].val) if len(cfvo) > 1 else None
            ),
            color=_color_value(db.color) if db.color else 'FF638EC6',
            show_value=bool(db.showValue) if db.showValue is not None else True,
        )
    if rule.type == 'iconSet' and rule.iconSet is not None:
        ic = rule.iconSet
        return IconSetRule(
            **common,
            icon_style=ic.iconSet or '3TrafficLights1',
            type=ic.cfvo[0].type if ic.cfvo else 'percent',
            values=tuple(
                _str_or_none(c.val) or '0' for c in (ic.cfvo or [])
            ),
        )

    raise ValueError(
        f'unsupported conditional format rule type: {rule.type!r}'
    )


def cf_to_openpyxl_rule(cf: ConditionalFormat) -> Rule:
    if isinstance(cf, CellIsRule):
        return XCellIsRule(
            operator=cf.operator,
            formula=list(cf.formula),
            fill=_fill_from_style(cf.style),
            stopIfTrue=cf.stop_if_true,
        )
    if isinstance(cf, FormulaRule):
        return XFormulaRule(
            formula=[cf.formula] if cf.formula else [],
            fill=_fill_from_style(cf.style),
            stopIfTrue=cf.stop_if_true,
        )
    if isinstance(cf, ColorScaleRule):
        return XColorScaleRule(
            start_type=cf.start_type,
            start_value=cf.start_value,
            start_color=cf.start_color,
            mid_type=cf.mid_type,
            mid_value=cf.mid_value,
            mid_color=cf.mid_color,
            end_type=cf.end_type,
            end_value=cf.end_value,
            end_color=cf.end_color,
        )
    if isinstance(cf, DataBarRule):
        return XDataBarRule(
            start_type=cf.start_type,
            start_value=cf.start_value,
            end_type=cf.end_type,
            end_value=cf.end_value,
            color=cf.color,
            showValue=cf.show_value,
        )
    if isinstance(cf, IconSetRule):
        return XIconSetRule(
            icon_style=cf.icon_style,
            type=cf.type,
            values=list(cf.values),
        )
    raise TypeError(f'unknown ConditionalFormat type: {type(cf).__name__}')


def _style_from_dxf(dxf: DifferentialStyle) -> Optional[CFStyle]:
    fill_color: Optional[str] = None
    if dxf.fill is not None:
        fg = getattr(dxf.fill, 'fgColor', None)
        if fg is not None:
            fill_color = fg.value or fg.rgb or None

    bold = italic = False
    font_color: Optional[str] = None
    if dxf.font is not None:
        bold = bool(dxf.font.b)
        italic = bool(dxf.font.i)
        if dxf.font.color is not None:
            font_color = dxf.font.color.value or dxf.font.color.rgb or None

    if not (fill_color or bold or italic or font_color):
        return None
    return CFStyle(
        fill_color=fill_color,
        font_bold=bold,
        font_italic=italic,
        font_color=font_color,
    )


def _fill_from_style(style: Optional[CFStyle]) -> Optional[PatternFill]:
    if style is None or not style.fill_color:
        return None
    return PatternFill(fill_type='solid', start_color=style.fill_color)


def _color_value(c: object) -> str:
    """Best-effort extraction of an openpyxl color to a hex string."""
    return getattr(c, 'value', None) or getattr(c, 'rgb', None) or ''


def _str_or_none(v: object) -> Optional[str]:
    if v is None:
        return None
    return str(v)
```

openpyxl exposes Excel tables via `worksheet.tables`, a dict from
table name to `openpyxl.worksheet.table.Table`. Each `Table` has:

- `displayName: str` — the table's user-facing name.
- `name: str` — usually equal to displayName.
- `ref: str` — the A1 range (e.g. `'A1:C10'`).
- `headerRowCount: int`
- `totalsRowCount: int`
- `tableColumns: list[TableColumn]` with per-column metadata
  (`name`, `calculatedColumnFormula`, `totalsRowLabel`,
  `totalsRowFunction`).
- `tableStyleInfo` — optional named style.

import openpyxl
from openpyxl.worksheet.table import Table, TableColumn

from claudesheets.xlsx.reader import read_xlsx
from claudesheets.xlsx.writer import write_xlsx


def _wb_with_table(path: Path) -> None:
    wb = openpyxl.Workbook()
    ws = wb.active
    ws.title = 'S'
    ws['A1'], ws['B1'], ws['C1'] = 'Region', 'Q1', 'Q2'
    for i, region in enumerate(['North', 'South', 'East'], start=2):
        ws.cell(row=i, column=1, value=region)
        ws.cell(row=i, column=2, value=10 * i)
        ws.cell(row=i, column=3, value=20 * i)

    cols = [
        TableColumn(id=1, name='Region'),
        TableColumn(id=2, name='Q1'),
        TableColumn(id=3, name='Q2'),
    ]
    t = Table(
        displayName='Sales',
        name='Sales',
        ref='A1:C4',
        headerRowCount=1,
        totalsRowCount=0,
        tableColumns=cols,
    )
    ws.add_table(t)
    wb.save(path)


def test_reader_picks_up_table(tmp_path: Path):

    _wb_with_table(src)
    wb = read_xlsx(src)
    s = wb.sheet('S')
    assert len(s.tables) == 1
    assert s.tables[0].name == 'Sales'
    assert s.tables[0].ref == 'A1:C4'
    assert [c.name for c in s.tables[0].columns] == [
        'Region',
        'Q1',
        'Q2',
    ]

@pytest.mark.parametrize('header_count', [0, 1, 2])
@pytest.mark.parametrize('totals_count', [0, 1])
def test_table_round_trips_with_varying_header_and_totals_rows(
    tmp_path: Path, header_count: int, totals_count: int
):
    """Cover the {0,1,2} header / {0,1} totals matrix.

    Excel allows 0 (rare, for borderless data tables), 1 (default),
    or 2 (header + sub-header) header rows. Totals row is 0 or 1.
    """
    src = tmp_path / f'in_h{header_count}_t{totals_count}.xlsx'
    wb = openpyxl.Workbook()
    ws = wb.active
    ws.title = 'S'
    # Layout: enough rows to fit headers + 3 data rows + optional totals.
    n_rows = max(header_count, 1) + 3 + totals_count
    for r in range(1, n_rows + 1):
        ws.cell(row=r, column=1, value=f'r{r}c1')
        ws.cell(row=r, column=2, value=r * 10)
    ref = f'A1:B{n_rows}'

    cols = [
        TableColumn(id=1, name='Label'),
        TableColumn(
            id=2,
            name='Value',
            totalsRowFunction='sum' if totals_count else None,
        ),
    ]
    t = Table(
        displayName='T',
        name='T',
        ref=ref,
        headerRowCount=header_count,
        totalsRowCount=totals_count,
        tableColumns=cols,
    )
    ws.add_table(t)
    wb.save(src)

    out = tmp_path / f'out_h{header_count}_t{totals_count}.xlsx'
    write_xlsx(read_xlsx(src), out)
    s = read_xlsx(out).sheet('S')

    assert len(s.tables) == 1
    assert s.tables[0].header_row_count == header_count
    assert s.tables[0].totals_row_count == totals_count
```

from pathlib import Path

from claudesheets.source.reader import read_source
from claudesheets.source.writer import write_source
from claudesheets.xlsx.reader import read_xlsx
from claudesheets.xlsx.writer import write_xlsx
from tests.fixtures.workbooks import write_tier2_xlsx


def _project_dir(tmp_path: Path) -> Path:
    p = tmp_path / 'proj'
    p.mkdir()
    (p / 'claudesheets.toml').write_text(
        '[project]\nname = "x"\n[build]\ncalc_engine = "libreoffice"\n'
    )
    (p / 'workbook.toml').write_text(
        '[workbook]\nname = "x"\nsheets = []\n'
    )
    (p / 'sheets').mkdir()
    (p / 'data').mkdir()
    return p


def test_tier2_features_round_trip_through_source(tmp_path: Path):
    src = tmp_path / 'in.xlsx'
    write_tier2_xlsx(src)
    project = _project_dir(tmp_path)

    wb_in = read_xlsx(src)
    write_source(wb_in, project)
    wb_via_src = read_source(project)

    s_in = wb_in.sheet('S')
    s_out = wb_via_src.sheet('S')

    assert s_out.frozen_panes == s_in.frozen_panes
    assert s_out.print_area == s_in.print_area
    assert s_out.comments == s_in.comments
    assert len(s_out.conditional_formats) == len(s_in.conditional_formats)
    assert {type(cf) for cf in s_out.conditional_formats} == {
        type(cf) for cf in s_in.conditional_formats
    }
    assert len(s_out.tables) == len(s_in.tables)
    assert s_out.tables[0].name == s_in.tables[0].name

@use(project)
def test_tier2_built_xlsx_evaluates_under_libreoffice():
    """Smoke test: the built xlsx is not corrupt.

    libreoffice will refuse to open malformed xlsx; this catches
    "we wrote a syntactically broken file" regressions early.
    Doesn't try to verify CF visual correctness — Plan 3 is
    structural fidelity, not engine semantics.
    """
    import shutil

    import pytest as _pytest

    if shutil.which('soffice') is None:
        _pytest.skip('LibreOffice (soffice) not on $PATH')

    from claudesheets.calc.libreoffice import LibreOfficeEngine

    p = project()
    built = p / 'build' / 'in.xlsx'
    result = LibreOfficeEngine().evaluate(built)
    # Non-empty result == soffice opened the file and produced cell
    # values for at least one sheet. We don't assert specific values.
    assert any(result.values()), (
        f'libreoffice returned empty result for {built}; '
        'the built xlsx may be corrupt'
    )
```
